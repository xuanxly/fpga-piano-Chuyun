# 七里香：D12 白键入门关卡

文件：`SONGS/QLX_EASY.CSV`。根据你提供的《七里香》简谱制作，曲：周杰伦。本关使用单音主旋律，共203次按键，34小节，80 BPM，约1分44秒；游戏自带的3秒倒计时另算。

## 放入 TF 卡并开始

1. 将 `QLX_EASY.CSV` 放进 TF 卡根目录下的 `SONGS` 文件夹，最终路径为 `/SONGS/QLX_EASY.CSV`。
2. 拷贝完成后安全退出存储设备。如果通过D12的USB DISK拷贝，完成手机操作并断开后，再点开发板上的 `EJECT DISK`，让FPGA重新读取卡。
3. 在D12的Home进入 `GAME`，翻页找到 `QLX_EASY.CSV` 并选择。已运行D12时，增加这份CSV就可以使用，无需重新烧录FPGA。
4. 第一次建议使用 `PRACTICE`，熟悉后再用 `CHALLENGE`。将音调柱/`TRANS`设为 **0**；钢琴或电钢琴均可。

蓝灯提示下一音，绿灯表示已按对或需要继续保持。短音轻点即可，长音按住；同一个键再次提示时，要先松开再按。实际压力键的门限和手感仍以你们的板子为准。

## 这版怎样改编

- 把简谱的`1`放在 **C4**，上方一点的`1`放在 **C5**。全部为白键，音域C4～F5，主要使用第二、三排。
- 略去器乐前奏、第二段主歌及其重复内容；保留一段主歌、副歌两遍和收尾。
- 连线延音合成一次长按；部分密集同音和装饰节奏改为较规整的八分音符。
- 最短触发间隔375ms，每个分离音之间预留90～120ms松手间隙；最长一次长按约3.63秒。
- 节奏按入门难度重新整理。希望音高接近图片所标原调时，可以尝试`TRANS +3`；谱面的琴键位置仍保持不变。

## 预听与核对

精简整理版未附带预听WAV；可用 `tools/make_qilixiang_level.py` 根据CSV的数据重新生成软件参考音色。游戏只需CSV，发声仍由按键驱动FPGA实时合成。

已用产品的C解析器检查全部203个事件的时间、时长和键位；并用实际 `game_engine28.v` 加速回放全关卡，模拟玩家203/203命中、0漏音、20300分，长音、连续同键、队列补充和结算正常。结束标记与实际装载器一致，采用 `chart.end+1`。这验证数字规则，实际玩家难度及实板手感待游玩确认。

工程内可编辑数据：`tf_card/chart_sources/QLX_EASY.json`。修改后运行 `tools/make_qilixiang_level.py` 重新生成，再运行 `tools/verify_qilixiang_level.py` 验证。原D12 HDL、固件、引脚和925A位流均保持。

本整理版已直接包含关卡CSV、可编辑JSON及生成脚本。直接游玩只需复制 `tf_card/SONGS` 中的谱面。
