## 必须核对或建议修改

1. **灯珠封装与引脚映射。** BOM 料号与封装名称不同，不足以直接判定错误，但必须对照实际库焊盘编号、尺寸及安装方向。厂家资料第 2～3 页定义：1=DO、2=GND、3=DI、4=VDD。必须保证各级 DO 接下一级 DI，不能把编号连续当成已验证串联顺序。

2. **独立供电和压降。** 厂家标注每个颜色通道 12mA；若 112 灯三色满亮，按该数值估算 LED 电流为 `112×3×12mA=4.032A`，功率在 5V 下约 20.16W，尚未计控制电路及供电余量。这是选型估算，不是实测电流或保证最大值。灯板电源应独立规划，不能由 FPGA GPIO 或单根普通杜邦线承担全板电流。还需根据实际铜厚、板尺寸、供电/地线宽度、连接器、线束及注电点核算压降和温升；程序亮度上限只能作为补充措施。

3. **去耦电容分布。** 本次取得的厂家 WS2812B-2020-V6 V1.4 资料第 5 页典型应用电路为每灯 VDD 配 100nF。本板是 112 灯配 28 个 100nF。建议按每颗灯附近一个 100nF 预留/调整，并为 U1 的 VCC/GND 就近配置一个 100nF。若用户已打样或具体批次有另行明确要求，应先核对实际资料与布局，再决定补焊和限亮测试，不直接声称现板必然失效。470µF 入口电容不能替代每处高频去耦。

4. **缓冲器和 FPGA 边界。** TI 的 SN74HCT125 推荐供电 4.5～5.5V，VIH 最低 2V，可用于 FPGA 3.3V 输出到 5V 灯板方向的缓冲。必须确认 14 脚 VCC、7 脚 GND、所用通道低有效 OE，以及所有未用输入/OE 的确定电平。不能把 5V 输出、5V 上拉或外部 5V 电源接回 FPGA 普通 GPIO。PDF 缺少网络名，当前不能给 U2/P1 的逐针接线结论，尤其应核对其电源是否会与开发板电源并接回灌。

5. **空间映射与机械位置。** 从正面位号可见各琴键行的编号方向交替。未来代码需要明确“ADC 板/通道 → 琴键行列 → 四颗灯 → 串行地址”的表，不能简单沿灯珠链依次点亮来冒充二维扩散。需要确认演奏者视角下每排 C～B 的方向及整板安装方向，并核对琴键、FSR、支架和背面元件是否干涉。

## 协议可行性（计算，非实测）

厂家资料给出 24bit GRB、高位先发、约 800kbps、帧间低电平复位大于 280µs。

- 112 灯一帧数据耗时约 `112×24/800000=3.36ms`。
- 加入不少于 300µs 的复位空闲，约 3.66ms；因此从发送带宽看，60Hz 灯效刷新可行。
- 发送逻辑应按实际 V6 数据手册的 0/1 高低脉宽实现，不能只按“800kHz”生成等占空比时钟。
- 这是协议预算，未验证当前 PCB 信号质量、供电、实际可达帧率或灯效观感。
