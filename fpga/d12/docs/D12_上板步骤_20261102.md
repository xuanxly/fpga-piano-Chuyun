# D12 上板步骤

说明：本文件保留交付时的数字验证记录。用户此后反馈D12已经烧录且基本功能可正常使用；手机磁盘、录音时长等具体项目请以你们的实测记录为准。

1. 保留D11恢复位流。打开 `../pressure_piano_touch.gprj`，或在Gowin Programmer直接选择 `../impl/pnr/pressure_piano_touch.fs`，使用 **SRAM Program**。
2. 下载后核对 **UserCode 0x0000925A**。先检查屏幕、28键耳机发声和音量/音调柱。原接线保持；TF卡使用时DIP第5/6位保持ON，避免BL616同时驱动共用SPI。其他启动位不因本次SRAM下载而更改。
3. 屏幕TOUCH接J18，USBA-Switch朝FPGA，长按PCB3按钮约2秒启用触控。长按不再顺带切换音色效果。
4. 将项目 `tf_card/SONGS/` 复制到TF卡根目录。进入GAME选歌曲，PRACTICE等待正确键，CHALLENGE固定节奏；可用实体键或触屏键。STOP停止并回到曲目列表。
5. PCB3短按：钢琴/电钢琴/风琴切明暗，吉他/弦乐切揉弦；五种音色分别记忆。指示灯显示当前效果，音色切换仍先停止旧琴音。
6. 录音保持内部PCM WAV。D12只播放16位PCM WAV，MP3不再解码。

## USB磁盘需要配套固件

`../firmware/release/piano_d12_ch569.hex` 是 **CH569固件，不能用Gowin Programmer下载**。只有FPGA更新时，USB DISK可能显示USB LINK WAIT。先阅读 [CH569升级与恢复](CH569_D12_UPGRADE.md)，准备官方恢复镜像、确认ISP配置和可读回备份，再进行CH569刷写。

配套固件就绪后，在FILES点USB DISK，再把iPhone数据线接CH569-USB3 Type-C。结束拷贝并弹出/拔线后点EJECT DISK，由程序重新挂载TF卡。拷贝中不要结束磁盘模式。只拔手机线不会自动收回卡。

## 已通过与待验证

- 30项RTL自检，真实FatFs在模拟128GB FAT32/exFAT卡上的两组集成测试、五分钟逐样本录音、USB协议与错误恢复测试。
- 新旧UI的16001帧随机对照覆盖五指归属、滑动、命令优先级和导航；UI提交增加一拍20ns。
- 五音色关闭揉弦时12500次D11精确对照，2232720次逐声部揉弦步长检查，896时钟/帧；112灯完整帧与八页面像素检查。
- Gowin建立/保持零违例，保留0.300ns额外建立预算；最小剩余 +0.283/+0.001ns。
- 原45球位不变，新增13路只走板内CH569连线；设备启动配置保持D11，USB与CH569数据输出均有INIT=1高阻保护。
- 实板耳机/灯光/TF卡速度、CH569刷写、iPhone识别/拷贝与整机总延迟待验收。没有自动操作硬件或Flash。
