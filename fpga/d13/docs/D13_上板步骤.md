# D13 上板与使用

保留原D12/925A位流。用SRAM Program下载本包D13 FS，核对User Code **0x0000C02F**。原PCB2/3/4、耳机和HDMI接线不变；TOUCH接J18，USBA-Switch朝FPGA，长按PCB3按钮约2秒启用触控。

Home两排四列，VERIFY为第七个、EFFECTS为第八个应用。SPECTRUM/KEYBOARD/RECORDER/FILES分别是频谱/键盘/录音/文件，TIMBRE/GAME是音色/游戏。实际版本以Home D13及烧录日志User Code核对。

效果页REVERB为混响、ECHO为回声、CHORUS为合唱。左侧按钮独立开关，右侧滑条分别调强度，三种可叠加，退出保持；录音保存带效果琴声，监听音量不改变录音，文件播放器不加效果。

VERIFY默认不发测试音。选择1/4/8/16/28/32后START，纯HDL实时生成375Hz步进至12kHz的测试声部；离开页面停止。STOP后可用实体键演示真实演奏。测试32声部与正常乐器28复音分开说明。

FS MEAS、LAST/MAX CYC、GATE-DAC、PCM PEAK来自硬件计数。LAST/MAX CYC观察正常28声部乐器引擎；32声部测试有另一条256周期流水线，不混用两者耗时。GATE-DAC只表示已判定门控到数字DAC装载非零PCM，测量前关闭效果并等待原尾音消失；整机模拟延迟仍需外部测量。触摸修复经过数字回归，实板是否完整改善仍须确认；异常时记录VERIFY内USB ERR/SKIP与顶部诊断行。

## 新标准I2S

|信号|位置|球位|
|---|---|---|
|BCLK|J13-1|E14|
|LRCLK/WS|J13-2|E13|
|DATA|J13-3|C15|
|GND|J13-12|GND|

三路均为3.3V数字输出；J13靠PCIe侧，不能与SDRAM0扩展板并用。11脚是5V，不接信号。16bit有效PCM、32bit左右时隙、48kHz，标准1bit延迟。原3.5mm继续工作。
